What this layer wants from a proposal:

  - Say which interface change went unevidenced and how you noticed. This layer
    catches an agent that cannot see what it built; a proposal is usually about where
    the boundary of "interface work" sits.
  - If the check fired on work with no visible surface, show the diff that triggered
    it. Over-firing is what teaches people to add the exemption reflexively.
  - Screenshot tooling varies enormously. Say what you used, because the layer
    deliberately holds no opinion and should learn where that costs you.
