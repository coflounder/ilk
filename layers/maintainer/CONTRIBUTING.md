What this layer wants from a proposal:

  - Say what the queue actually looked like. A ceiling is a judgement about
    attention, and "12 was wrong for us" means little without the shape of the
    backlog it was wrong for.
  - Distinguish a check that was wrong from a check that was right and unwelcome.
    Both are worth sending; only the first is a bug.
  - If a rubric question misled you, say which one and what it made you conclude.
    The rubric is the layer's actual product; the checks only enforce that it was
    used.
