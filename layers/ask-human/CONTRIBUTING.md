What this layer wants from a proposal:

  - Say what the agent was actually blocked on. This layer's premise is that an
    agent guessing is worse than an agent stopping, and a proposal to loosen it needs
    to argue against that premise directly rather than around it.
  - If the check was too aggressive, show the question that triggered it. A question
    that should not have blocked is the most useful thing you can send.
  - Report how long questions sat unanswered. A layer that makes stopping cheap and
    answering expensive has failed in a way no single repository can see.
